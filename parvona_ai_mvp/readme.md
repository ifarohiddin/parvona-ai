# Parvona AI — Netlify MVP

This is a static MVP/landing demo designed for the Parvona AI project.

## Deploy to Netlify

1. Open Netlify.
2. Drag and drop this project folder (or the ZIP after extracting it) into Netlify Drop.
3. Netlify will create a public URL.
4. You can later update the same Netlify site without changing the public URL.

## Files

- `index.html` — Main website
- `styles.css` — Responsive design
- `script.js` — MP4 demo interaction
- `assets/parvona-ai-logo.png` — Logo
- `netlify.toml` — Netlify configuration

## Important

The current MP4 analysis button is a visual MVP simulation. Connect it to your real AI backend/API when ready.
